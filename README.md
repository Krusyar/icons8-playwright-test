# Icons8 Playwright E2E Test 🚀

**Тестовое задание на позицию Junior QA Engineer (AI Automation) в команду Icons8.**

Данный репозиторий содержит автоматизированный сквозной (E2E) автотест, написанный с использованием Playwright (JavaScript) и ИИ-ассистента. Скрипт проверяет базовый сценарий: поиск иконки по ключевому слову, загрузку сетки результатов и успешное открытие панели деталей выбранной иконки.
